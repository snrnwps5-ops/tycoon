# 난이도 시뮬레이터

`node tests/sim/sim.js [free|boost|vip] [날짜들] [GAP]`

- 날짜는 0부터 센다(5 = DAY 6). GAP은 플레이어가 손님 1명을 응대하는 간격(게임 초)이다. 6은 능숙, 8은 보통, 12는 느긋한 플레이어다. 99999는 플레이어가 아무것도 안 하고 직원만 일한다.
- 지점마다 '무과금으로 무난히 투자한' 상태(`PROG`: 업그레이드·직원·자동화)를 가정한다. 결과는 매출/목표 비율이고, 1.0 이상이면 클리어다.
- 날짜 하나에 약 1~2분 걸린다. 같은 날도 손님이 무작위라 ±0.3 정도 흔들리므로 두세 번 돌려 평균을 본다.
